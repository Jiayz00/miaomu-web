# PRD - 盆景艺术展示与销售平台产品需求文档

## 1. 产品定位

面向盆景爱好者与收藏家的高端盆景展示平台，提供盆景信息展示、在线询价、收藏管理等服务。管理员可通过后台管理商品、分析数据。

## 2. 用户角色

| 角色 | 权限 |
|------|------|
| 游客 | 浏览盆景列表/详情、查看分类、搜索 |
| 注册用户 | 游客权限 + 收藏、询价聊天、个人信息管理 |
| 管理员 | 全部权限 + 商品CRUD、分类管理、图片编辑、用户管理、数据分析 |

## 3. 功能需求

### 3.1 用户端

#### 3.1.1 首页
- Hero 大图轮播（盆景艺术展示，呼吸感动效）
- 精选盆景展示（6-8 个，悬停动效）
- 分类导航（松柏类、杂木类、花果类、山水盆景等）
- 品牌故事区域
- 浏览量统计埋点

#### 3.1.2 盆景列表页
- 分页展示（每页 12 个）
- 筛选：分类、价格区间、产地、年份
- 排序：最新、价格、热门
- 搜索框（关键词搜索名称/描述）
- 卡片式布局：主图、名称、价格、产地、年份
- 收藏按钮（登录后可用）

#### 3.1.3 盆景详情页
- 多图展示（主图 + 缩略图切换）
- 完整信息：名称、价格、库存、产地、年份、树龄、尺寸、分类、描述
- 询价按钮 → 创建/进入聊天会话
- 收藏/取消收藏
- 浏览量 +1（埋点）
- 相关推荐（同分类盆景）

#### 3.1.4 用户认证
- 注册（用户名/邮箱 + 密码）
- 登录（JWT）
- 退出登录
- Token 自动刷新

#### 3.1.5 收藏功能
- 收藏/取消收藏盆景
- 我的收藏列表页
- 收藏列表支持移除

#### 3.1.6 询价聊天
- 创建询价会话（关联盆景商品）
- 实时消息收发（Socket.io）
- 历史消息查看
- 会话列表
- 管理员回复

#### 3.1.7 个人中心
- 个人信息查看/修改
- 我的收藏
- 我的询价记录

### 3.2 管理员端

#### 3.2.1 数据看板（Dashboard）
- 核心指标卡片：总盆景数、总用户数、总浏览量、总收藏量
- 浏览量趋势图（近 7/30 天折线图）
- 收藏量趋势图（近 7/30 天）
- 热门盆景 TOP10（按浏览量/收藏量排序）
- 分类占比（饼图）
- 最新询价列表

#### 3.2.2 盆景管理
- 列表页（分页、搜索、筛选）
- 新增盆景：名称、价格、库存、产地、年份、树龄、尺寸、分类、描述、多图上传
- 编辑盆景：全字段编辑、图片增删
- 删除盆景（软删除）
- 上架/下架

#### 3.2.3 分类管理
- 分类列表（树形/列表）
- 新增/编辑/删除分类
- 分类排序

#### 3.2.4 图片管理
- 图片上传（拖拽 + 点击）
- 图片压缩优化（Sharp）
- 图片预览/删除
- 支持设为主图

#### 3.2.5 用户管理
- 用户列表
- 查看/禁用用户
- 重置用户密码

#### 3.2.6 询价管理
- 询价会话列表
- 回复用户询价（聊天界面）
- 标记已处理/未处理

## 4. 非功能需求

### 4.1 性能
- 首页 LCP < 2.5s
- API 响应 < 200ms（P95）
- 支持并发 100 用户

### 4.2 安全
- HTTPS 全站
- SQL 注入/XSS/CSRF 防护
- API 速率限制
- 密码加密存储
- JWT 短期 Token + Refresh Token

### 4.3 设计风格
- 参考 https://www.herons.co.uk/ 的高级感
- 配色：深绿/墨绿为主，金色点缀，米白背景
- 字体：衬线体标题（高级感）+ 无衬线正文
- 动效：呼吸感、淡入淡出、平滑过渡，不过度炫技
- 响应式：桌面优先，兼容平板/手机

## 5. 拓展功能

- 盆景养护知识文章模块
- 盆景评分/评论系统
- 邮件通知（询价回复通知）
- 数据导出（CSV）
- 多语言支持预留（i18n）
